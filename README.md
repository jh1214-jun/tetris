# Tetris

순수 HTML, CSS, JavaScript로 만든 싱글 플레이어 테트리스 게임입니다. 설치나 로그인 없이 브라우저에서 실행하며, 블록을 쌓아 가로줄을 완성하고 점수를 올릴 수 있습니다.

초기 버전에 포함된 기능입니다.

- 10 × 20 보드와 7종 테트로미노(I, O, T, S, Z, J, L)
- 자동 하강, 좌우 이동, 시계 방향 회전, Soft Drop과 Hard Drop
- 벽·바닥·블록 충돌 판정과 블록 고정
- 여러 줄 동시 삭제와 실시간 점수 표시
- 다음 블록 미리보기와 점수에 따른 레벨·낙하 속도 변화
- 게임 오버 안내와 다시 시작
- 화면 크기에 따라 배치를 조정하는 반응형 캔버스

## 실행 방법

1. 프로젝트 파일을 내려받습니다.
2. `index.html`, `style.css`, `script.js`를 같은 폴더에 둡니다.
3. `index.html`을 더블클릭해 브라우저에서 엽니다.

별도의 개발 서버, 패키지 설치, 빌드 과정이 필요하지 않습니다. 페이지를 열면 게임이 바로 시작됩니다.

## 조작법

| 키·버튼 | 동작 |
|---|---|
| ← / → | 블록을 왼쪽 / 오른쪽으로 한 칸 이동 |
| ↑ | 시계 방향으로 90도 회전 |
| ↓ | 한 칸 빠르게 하강(Soft Drop), 길게 누르면 반복 |
| 스페이스바 | 가능한 가장 아래 위치로 즉시 하강한 뒤 고정(Hard Drop) |
| 다시 시작 | 보드·점수·레벨을 초기화하고 새 게임 시작 |

벽이나 다른 블록에 막힌 이동·회전은 취소됩니다. 새 블록이 등장할 공간이 없으면 게임 오버가 되며 자동 하강과 키 조작이 멈춥니다.

## 점수와 레벨

| 한 번에 지운 줄 | 획득 점수 |
|---|---:|
| 1줄 | 100점 |
| 2줄 | 300점 |
| 3줄 | 500점 |
| 4줄 | 800점 |

- 레벨은 1부터 시작하며, 1,000점마다 1씩 올라갑니다.
- 자동 하강 간격은 처음 500ms이며, 레벨마다 40ms씩 줄어 최소 100ms를 유지합니다.
- Soft Drop과 Hard Drop에는 추가 점수를 부여하지 않습니다.
- 다시 시작하면 점수 0, 레벨 1, 하강 간격 500ms로 돌아갑니다.

## 화면 지원

보드는 1:2, 미리보기는 1:1 비율을 유지하며 화면 크기에 맞춰 줄어듭니다. 화면 너비가 480px 이하이면 점수·레벨·미리보기 패널이 보드 아래에 표시됩니다. 모바일 화면에서도 배치는 조정되지만 플레이에는 키보드가 필요합니다.

## 프로젝트 구성

```text

├── style.css           # 화면 배치와 반응형 스타일
├── script.js           # 게임 데이터·로직·입력·렌더링
├── tests/game.test.cjs # 자동 테스트
├── PRD.md              # 제품 요구사항

```

## 테스트

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다. Node.js는 테스트에만 필요합니다.

```sh
node --check script.js
node --test tests/game.test.cjs
```

최근 검증에서 자동 테스트 18개가 모두 통과했습니다. 7종 생성, 이동·회전·하강, 충돌, 라인 삭제, 4줄 800점, 게임 오버·재시작, 미리보기, 레벨별 속도를 검증합니다.

테스트는 DOM·캔버스·시간을 제어한 환경에서 실행합니다. 실제 브라우저 화면과 물리 키 입력은 별도 확인이 필요합니다.

## GitHub Pages 배포 점검

- 배포 대상 폴더에는 `index.html`, `style.css`, `script.js`가 함께 있어야 합니다.
- 브랜치에서 배포한다면 현재 프로젝트 파일이 있는 `master` 브랜치의 루트 폴더를 소스로 확인합니다.
- CSS와 JavaScript는 상대 경로로 연결되어 저장소 하위 경로에서도 참조할 수 있습니다.
- 실제 Pages 설정과 배포 주소를 확인한 후 위 데모 링크를 교체합니다.

로그인, 멀티플레이, 랭킹 서버, Hold, Ghost Piece, 터치 조작, 사운드는 현재 버전에 포함하지 않습니다.
