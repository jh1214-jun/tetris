# Tetris MVP — 실행 To-Do

[PRD.md](./PRD.md)를 기준으로 구현한다. 아래 작업은 의존성을 고려한 구현 순서이며, 각 단계의 완료 기준을 검증한 후 다음 단계로 진행한다. 테스트는 DOM 없이 실행하는 게임 로직 단위 테스트와 UI 통합 검증으로 나눈다.

PRD에 없는 세부 규칙은 MVP 기본값으로 정한다. ←/→는 좌우 이동, ↑는 시계 방향 회전, ↓는 Soft Drop, 스페이스바는 Hard Drop이다. 초기 자동 하강 간격은 0.5초이며, 한 번에 제거한 1/2/3/4줄에 각각 100/300/500/800점을 부여한다. Soft Drop에는 추가 점수를 부여하지 않는다. 막힌 회전은 취소하고, 새 블록을 생성할 공간이 없으면 Game Over로 판정한다.

## 실행 및 조작

index.html을 더블클릭하면 브라우저에서 바로 실행된다. 설치, 개발 서버, 프레임워크, 빌드 도구가 필요 없다.

| 입력 | 동작 |
|---|---|
| ← / → | 좌우 한 칸 이동 |
| ↑ | 시계 방향 회전; 벽이나 블록에 막히면 취소 |
| ↓ | 한 칸 Soft Drop; 길게 누르면 반복 |
| 스페이스바 | 가능한 가장 아래 위치로 Hard Drop 후 즉시 고정 |
| 다시 시작 버튼 | 진행 중 또는 게임 오버 후 보드·점수를 초기화 |

레벨 1에서는 0.5초마다 자동 하강하며, 생성 공간이 막히면 게임 오버를 표시하고 멈춘다. 한 번에 제거한 1/2/3/4줄은 100/300/500/800점을 더하며 우측 점수에 즉시 표시한다.

## 테스트

Node.js가 있는 환경에서 `node --test tests/game.test.cjs`를 실행한다. Node.js는 테스트용이며 게임 실행에는 필요 없다.

자동 하강, 7종 경계·충돌, 회전 취소·원본 보존, 키 입력, Hard Drop, 다중 라인 제거, 점수 표시, 게임 오버 및 반복 재시작에 대한 18개 테스트가 통과했다. 추가 검증 항목은 미리보기와 실제 다음 블록의 일치, 7종 미리보기 렌더링, 레벨 경계와 속도 복원, 레벨 상승과 게임 오버의 동시 처리다. 테스트는 캔버스·DOM·타이머를 대체한 환경에서 수행했으며 실제 브라우저 플레이 검증은 별도다.

## 다음 블록·레벨·반응형 화면

다음 블록 미리보기에 표시된 블록은 현재 블록을 고정한 직후 실제 활성 블록으로 등장한다. 재시작 시 현재 블록과 다음 블록을 모두 새로 생성한다.

레벨은 1,000점마다 1씩 올라간다. 하강 간격은 레벨 1에서 500ms, 레벨 2에서 460ms, 레벨 3에서 420ms이며 레벨마다 40ms씩 줄어 최소 100ms를 유지한다. 점수표 자체는 레벨에 따라 변경하지 않는다. 재시작하면 레벨 1과 500ms로 복원된다.

게임 보드는 가로:세로 1:2, 미리보기는 1:1 비율을 유지하며 화면 크기에 맞춰 축소한다. 너비 480px 이하에서는 상태 패널을 보드 아래에 배치한다. 작은 화면의 표시를 지원하며 조작은 기존 키보드를 사용한다.

자동화 브라우저의 보안 정책이 로컬 file URL 열기를 차단하여 반응형 화면을 실제 브라우저에서 확인하지 못했다. index.html을 직접 열고 작은 화면·가로 화면에서 보드 비율과 패널 배치를 확인해야 한다.
